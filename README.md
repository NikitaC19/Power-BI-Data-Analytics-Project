# Power-BI-Data-Analytics-Project

Project Name: Nirali Ecommerce Sales Dashboard

Description:
Developed an interactive e-commerce sales dashboard using Microsoft Power BI to analyze sales, profit, quantity, customer performance, and payment methods. Created KPI cards, charts, and slicers to track key business metrics and compare sales across states, categories, months, and sub-categories. The dashboard helps identify sales trends and supports data-driven decision-making.

Skills: Microsoft Power BI, Data Visualization, Data Analysis, Dashboard Development, Business Intelligence.
